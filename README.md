# 🚇 Rail Rush

Ein schneller Endless Runner im Browser – ähnlich wie Subway Surfers.

## ▶️ Jetzt spielen

**https://tillwassenhoven1-glitch.github.io/Subway-Surfers/**

Keine Installation, kein Konto nötig – läuft auf Handy, iPad und PC. 🎮

## So funktioniert's

- 🏃 Deine Figur rennt automatisch über die Gleise – 3 Spuren, immer schneller
- 👮 Der Kontrolleur und sein Hund sind dir auf den Fersen
- 🚆 Weiche Zügen und Absperrungen aus – frontal reinlaufen = Game Over
- 😬 Seitlich streifen = Stolpern – stolperst du nochmal, bevor er weg ist, wirst du erwischt!
- 🪙 Sammle Münzen und gib sie im Shop aus

## Steuerung

| | PC | Handy / iPad |
|---|---|---|
| ⬅️➡️ Spur wechseln | Pfeiltasten / A D | Wischen |
| ⬆️ Springen | ↑ / W | Nach oben wischen |
| ⬇️ Rollen | ↓ / S | Nach unten wischen |
| 🛹 Hoverboard | Leertaste | Doppeltippen |
| ⏸ Pause | P / Esc | ⏸-Taste |

## Features

- 🚧 Niedrige & hohe Absperrungen (springen oder rollen), Absperrungen mit Licht
- 🛤️ Rampen auf die Zugdächer – von Zug zu Zug springen
- 🚄 Stehende und entgegenkommende Züge, Tunnel & Signalmasten
- 🚀 Power-ups: Jetpack, Super-Sneaker, Münzmagnet, 2× Multiplikator, Mystery Box
- 🛹 Hoverboard: 30 s Schutz – crasht man, geht nur das Board kaputt
- 🎯 Missionen im 3er-Set – jedes geschaffte Set: Multiplikator +1 (bis ×30)
- 🔑 Schlüssel: nach Game Over weiterlaufen (1, 2, 4, 8 … 🔑)
- 🛒 Shop: Power-up-Upgrades (6 Stufen), Hoverboards, Headstart, Score Booster, Mystery Box
- 🧍 6 Figuren & 🎨 6 Board-Designs zum Freischalten
- 🔐 Cheat-Menü (Code nötig 😉)
- 💾 Highscore, Münzen & Fortschritt werden lokal gespeichert
- 🗺️ Strecke wird zufällig zusammengesetzt – je weiter, desto mehr Züge
